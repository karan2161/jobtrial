# Job Trail Repair Package

This package is a clean source copy of the uploaded Job Trail project.
Secrets and dependency caches are intentionally excluded.

## Local setup
1. Restore your environment variables from your own secure `.env`.
2. Install dependencies in the frontend/backend projects.
3. Start the backend and frontend according to the existing project scripts.
4. Run the project's test suite.

## Important
Do not commit `.env` or API keys to source control.
